# Café Aroma

Sitio web estático de ejemplo para una cafetería, creado como pre-entrega de HTML y CSS.

## Archivos

- `index.html`: estructura semántica, navegación interna, menú de productos, reseñas, mapa embebido y formulario de contacto.
- `styles.css`: estilos externos, Google Fonts, Flexbox para las cards de productos, Grid para las reseñas y Media Queries para pantallas pequeñas.

## Cómo abrirlo

Abrí `index.html` en un navegador. No requiere instalación ni JavaScript.

## Activar el formulario con Formspree

1. Creá un formulario en [Formspree](https://formspree.io/).
2. Copiá el endpoint que te proporciona Formspree.
3. En `index.html`, reemplazá `https://formspree.io/f/REEMPLAZAR_ID` por el endpoint real.
4. Enviá un mensaje de prueba y verificá la recepción.

El formulario no enviará mensajes correctamente hasta que se configure ese endpoint.

## Publicar en GitHub Pages

1. Subí `index.html`, `styles.css` y `README.md` a un repositorio de GitHub.
2. En el repositorio, abrí **Settings → Pages**.
3. Seleccioná la rama principal y la carpeta raíz (`/root`) como fuente, y guardá.
4. Esperá a que GitHub Pages genere la URL pública.

También podés arrastrar la carpeta del proyecto a Netlify para desplegarla.

## Antes de entregar

- Cambiá la dirección, el teléfono y el correo de ejemplo por los datos que quieras mostrar.
- Los precios del menú son ilustrativos.
- El mapa es una búsqueda genérica de cafeterías en Buenos Aires; reemplazala por la ubicación elegida.
- Configurá Formspree con tu endpoint real.
- Google Fonts y el mapa embebido necesitan conexión a Internet.
